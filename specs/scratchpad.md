# Разработка приложения для отображения раскладки клавиатуры рядом с курсором

## Задача

Разработать приложение, которое для текущей раскладки клавиатуры показывает соответствующий флаг страны или кодовое обозначение языка рядом с курсором.

Раскладки только две: русская и английская.

Требуется минимальный расход ресурсов приложением и максимально быстрая реакция на смену раскладки.

## Работа приложения

### Варианты работы с курсором

Предлагается оставить системный курсор, не заменять его, а флаг отображать отдельным небольшим графическим элементом рядом с ним.

Этот подход даст несколько преимуществ:

* Не придётся создавать собственные варианты для всех системных курсоров.
* Не придётся вмешиваться в работу приложений.
* Можно независимо настраивать размер и положение флага.
* можно быстро менять флаг при переключении раскладки.

### Основные части приложения

Программа может состоять из 4 небольших компонентов:

* Монитор раскладки

    Определяет текущую раскладку активного окна.

* Определитель языка

    Русский -> Ru, Английский -> En.

* Графический оверлей

    Прозрачное окно с флагом поверх рабочего стола.

* Модуль позиционирования

    Перемещение флага вслед за курсором мыши.

### Техническая реализация

| Компонент                                  | Технология                       |
| ------------------------------------------ | -------------------------------- |
| Язык программирования                      | C++                              |
| API                                        | Win32 API                        |
| Определение раскладки                      | GetKeyboardLayout                |
| Определение активного окна                 | GetForegroundWindow              |
| Определение позиции мыши                   | GetCursorPos                     |
| Отображение флага                          | Layered Window                   |
| Прозрачность и отсутствие перехвата кликов | WS_EX_LAYERED, WS_EX_TRANSPARENT |
| Работа в фоне                              | Message Loop                     |
| Иконки флагов                              | PNG                              |

### Отображение флага

Программа должна поддерживать 3 варианта отображения раскладки рядом с курсором:

1. Флаг России или флаг Великобритании.
2. Флаг России или флаг США.
3. Графические значки с текстом RU и EN с фоном разного цвета (например, синий и красный).

Должна быть возможность настройки положения флага относительно курсора.

Флаг должен отображаться рядом с курсором для всех приложений.

### Как минимизировать потребление ресурсов

Стоит придерживаться следующих принципов:

1. Никакого постоянного интенсивного опроса системы.
2. Проверять изменение раскладки примерно раз в 50–100 мс либо использовать события Windows там, где это возможно.
3. Обновлять позицию оверлея только при перемещении мыши.
4. Загружать изображения флагов один раз при запуске.
5. Не создавать новые графические объекты при каждом перемещении курсора.
6. Не использовать анимацию, если она не нужна.
7. Не создавать отдельный поток для каждой задачи.

В результате получится небольшая фоновая программа, которая практически не будет нагружать процессор.

### Последовательность разработки

Начать с небольшого нативного Win32-приложения без графического интерфейса настроек. Сначала добиться безупречной работы оверлея, определения раскладки и позиционирования. А настройки, автозапуск и системный трей добавить следующим этапом.

Особенно важно правильно определить раскладку.

В Windows раскладка может быть разной в разных приложениях. Поэтому недостаточно просто проверить язык текущего потока нашей программы. Нужно получить поток активного окна через `GetWindowThreadProcessId`, а затем запросить его раскладку через `GetKeyboardLayout`.
